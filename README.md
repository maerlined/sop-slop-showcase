# sop-slop showcase

The public page for **sop-slop** (SOP-001), the quality system for a one-person workspace where several Claude Code sessions build, review and hand over work side by side: working rules, best practices for planning, executing and testing, procedures, machine specs, and a deviation register.

The sop-slop repo itself is private: it holds working notes and records about real projects. This repo holds only a curated description of how the system works.

**Live page:** https://maerlined.github.io/sop-slop-showcase/

## What's here

| File | What it is |
|---|---|
| `index.html` | The showcase page: one static file, no scripts, no external requests |
| `.nojekyll` | Serves the page as is on GitHub Pages |
